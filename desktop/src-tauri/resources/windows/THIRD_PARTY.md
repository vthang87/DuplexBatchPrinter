# Third-party software (Windows)

## SumatraPDF

Windows silent PDF printing uses a bundled [SumatraPDF](https://www.sumatrapdfreader.org/) portable binary.

- License: GNU GPLv3
- Download helper: `desktop/scripts/download-sumatra.sh`
- Expected path: `src-tauri/resources/windows/SumatraPDF.exe`

Distributors of Windows builds that include SumatraPDF must comply with GPLv3 (provide corresponding source / license notices).
